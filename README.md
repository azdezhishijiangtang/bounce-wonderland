# 弹跳奇境 · Bounce Wonderland

一个"万物有物理、地图会呼吸"的卡通开放世界物理沙盒原型。你扮演误入奇境的小家伙「波波」，用**抓取投掷、变大变小、弹跳板**在漂浮群岛间撒野，把整个世界当成玩具。

> 🎮 在线试玩（平板/手机/桌面均可）：**https://azdezhishijiangtang.github.io/bounce-wonderland/**

---

## 特性

- **无缝大地图**：3400×2400 开放世界，相机跟随，右上角小地图
- **物理沙盒**：抓取最近物体、朝任意方向甩出、箱子被砸碎会掉星星、物体互相碰撞
- **移动即爽点**：冲刺、变大推开一切、变小钻缝、踩弹跳板被弹飞
- **活着的 world**：昼夜循环叠色 + 夜晚冒萤火虫
- **有性格的 NPC**：3 个角色，靠近按对话键开启多轮搞笑台词
- **目标系统**：集齐 10 颗星星后找镇长"通关"

## 操作

### 桌面端（键盘 + 鼠标）
| 操作 | 按键 |
|------|------|
| 移动 | `WASD` / 方向键 |
| 冲刺 | `空格` |
| 抓取最近物体 | `E`（再按放下） |
| 投掷 | 抓住后**鼠标左键**（朝鼠标方向甩出） |
| 变大 / 变小 | `Q` / `R` |
| 与 NPC 对话 | 靠近后按 `F` |

### 平板 / 手机（自动启用触屏 UI）
- **左侧虚拟摇杆**：拖动控制移动方向与速度
- **右侧按钮**：⚡冲刺、✋抓/放、🚀投掷、🔼变大、🔽变小、💬对话
- 已禁用页面滚动与双指缩放，按钮尺寸随屏幕自适应
- 竖屏时提示横屏；开始游戏会尝试锁定横屏（受浏览器支持限制，iOS Safari 可能不生效，但可手动横屏）

## 本地运行

无需构建、无需依赖，单文件即可运行：

```bash
# 方式一：直接用浏览器打开
打开 index.html

# 方式二：起一个本地静态服务器（推荐，避免某些浏览器的本地文件限制）
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术

- 纯 **HTML5 Canvas + 原生 JavaScript**，零依赖、零构建
- 移动端优先：Pointer 事件统一鼠标/触屏，安全区（`env(safe-area-inset-*)`）适配刘海与底部手势条
- 物理为轻量自研：圆-圆碰撞 + 基于质量的分离 + 弹性反射
